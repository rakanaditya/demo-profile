Panduan Integration Vercel & GitHub Environment

Langkah lengkap menghubungkan Discord OAuth2 ke backend Vercel tanpa bocor credentials.

1 Buat Aplikasi di Discord Developer Portal

  1. Buka Discord Developer Portal dan login.
  2. Klik New Application, beri nama aplikasi Anda (misal: My Discord Profile Web).
  3. Masuk ke tab OAuth2 di menu sebelah kiri.
  4. Di bagian Redirects, tambahkan URI aplikasi Vercel Anda, misalnya:
    https://nama-project-anda.vercel.app/api/auth/callback
  5. Salin Client ID dan Reset/Salin Client Secret Anda.

2 Konfigurasi Environment Variables di Vercel

Masuk ke Dashboard Vercel → Pilih Project Anda → Settings → Environment Variables, lalu tambahkan 3 variabel berikut:

DISCORD_CLIENT_ID Contoh: 1234567890123456789
DISCORD_CLIENT_SECRET Contoh: AbCdEfGhIjKlMnOpQrStUvWxYz123456
DISCORD_REDIRECT_URI Contoh: https://nama-app.vercel.app/api/auth/callback

3 Contoh Serverless Route (Vercel Node.js / Next.js)

Gunakan kode berikut di file /api/auth/callback.js untuk pertukaran code dengan Token Discord: 

// api/auth/callback.js (Vercel Serverless Function)
export default async function handler(req, res) {
  const { code } = req.query;

  if (!code) {
    return res.status(400).json({ error: 'Missing code parameter' });
  }

  try {
    // 1. Tukar auth code dengan access token
    const tokenResponse = await fetch('https://discord.com/api/oauth2/token', {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        client_id: process.env.DISCORD_CLIENT_ID,
        client_secret: process.env.DISCORD_CLIENT_SECRET,
        grant_type: 'authorization_code',
        code: code,
        redirect_uri: process.env.DISCORD_REDIRECT_URI,
      }),
    });

    const tokenData = await tokenResponse.json();

    if (!tokenData.access_token) {
      return res.status(400).json({ error: 'Failed to retrieve access token', details: tokenData });
    }

    // 2. Fetch User Profile dari Discord API resmi
    const userResponse = await fetch('https://discord.com/api/users/@me', {
      headers: {
        authorization: `${tokenData.token_type} ${tokenData.access_token}`,
      },
    });

    const userData = await userResponse.json();

    // 3. Return user data ke frontend web Anda
    res.status(200).json({ user: userData, token: tokenData });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
}
