Tutorial Penggunaan Bot Commands di Discord

Semua command di bawah ini dapat langsung Anda ketikkan di kolom chat server Discord yang sudah terhubung dengan bot Rakan Aditya Community.

/giveaway list Event & Hadiah

Menampilkan daftar event & giveaway aktif yang sedang berlangsung beserta sisa waktu dan tautan ke website.

💡 Cara Pakai: Ketik /giveaway list di chat Discord untuk melihat event yang sedang berjalan.
/giveaway start Khusus Admin/Owner

Membuat event giveaway baru dan mengirimkan pesan pengumuman interaktif langsung ke channel pilihan.

💡 Cara Pakai: Ketik /giveaway start, lalu isi parameter judul, hadiah, jumlah pemenang, durasi (nilai & satuan waktu), serta channel tujuan.
/gacha roll Waifu Hub

Melakukan gacha summon waifu langsung dari Discord menggunakan 50 Poin akun Anda.

💡 Cara Pakai: Ketik /gacha roll. Jika poin mencukupi, bot akan menampilkan kartu karakter waifu (R, SR, SSR) secara acak!
/gacha profile Waifu Hub

Melihat statistik poin, jumlah koleksi waifu, login streak, serta total kemenangan PvP Anda.

💡 Cara Pakai: Ketik /gacha profile untuk melihat ringkasan status akun waifu yang terhubung dengan Website Waifu Hub.
/givepoint Khusus Admin/Owner

Memberikan atau menambahkan poin gacha waifu kepada user tertentu langsung ke database MongoDB.

💡 Cara Pakai: Ketik /givepoint target:@User jumlah:1000 untuk mengirim poin.
/removepoint Khusus Admin/Owner

Mengurangi atau mencabut poin gacha waifu dari user tertentu (dilengkapi proteksi agar tidak minus).

💡 Cara Pakai: Ketik /removepoint target:@User jumlah:500 untuk mengurangi poin.
